# Week 5: Array and Object Drills

## Project Overview
This project practices JavaScript arrays and objects through data manipulation exercises and a dashboard interface.

## Features
- JavaScript array and object exercises
- Order data calculations
- Dashboard statistics and summary cards
- Orders table and filtering
- Responsive layout using CSS Grid and Flexbox
- Styling with Tailwind CSS

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES Modules)
- Vite
- Tailwind CSS v4
- Git and GitHub

## Project Structure
- `data.js` — sample order data
- `drills.js` — array and object exercises
- `dashboard/` — dashboard application
- `dashboard/src/main.js` — dashboard functionality
- `dashboard/src/style.css` — dashboard styles

## Run Locally
1. Open the `dashboard` folder in your terminal.
2. Install dependencies:
   `npm install`
3. Start the development server:
   `npm run dev`
4. Open the local URL displayed in the terminal.

## Production Build
Inside the `dashboard` folder, run:

`npm run build`
